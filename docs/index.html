ПРОБЛЕМА

Слово набрано — буквы чужие

Клавиатура осталась в одной раскладке, а на экране — буквы из другой. Пока слово не прочитано дважды, ошибка не видна: это просто незнакомый набор символов. Стереть, переключить раскладку, набрать заново — маленькая потеря, которая повторяется по многу раз в день.

Rukey замечает это в момент набора: слово уже написано, раскладка уже не та — и возвращает вам то, что вы хотели сказать.

КАК РАБОТАЕТ

Два словаря и одна проверка

Внутри приложения — два словаря: ≈46 000 английских и ≈48 000 русских слов. Каждое слово проверяется по ним и по перевёрнутой раскладке. Исправление срабатывает, только если исходное написание в словаре отсутствует, а перевёрнутое — есть. Поэтому уже набранное правильное слово остаётся нетронутым, а ошибочное — превращается в нужное.

Словари встроены в приложение: всё работает офлайн, без обращений к сети.

Приложение в меню-баре и демон rukey используют один и тот же движок из RukeyCore — поведение у них одинаковое.

Один тап Option — и отмена

Если исправление оказалось лишним, нажмите Option один раз: Rukey вернёт исходный текст. Когда одно и то же слово отменяют несколько раз, приложение запоминает его и перестаёт трогать.

Защищённый ввод

В полях с Secure Input — например, в полях паролей — Rukey автоматически отступает и ничего не меняет.

Меню-бар и CLI

Меню-бар

В строке меню Rukey показывает состояние и текущую раскладку. Оттуда же открываются «Настройки…» и «Журнал…», а «Проверить обновления…» запускает проверку через Sparkle.

Работает · Приостановлено: защищённый ввод · Нет прав Accessibility

CLI

Демон rukey — тот же движок без интерфейса. Он собирается из исходников и в .dmg не входит — запускается через swift run rukey.

swift run rukey
swift run rukey --check-permissions
swift run rukey --exclude-terminals
swift run rukey --exclude-bundle <id>
swift run rukey --test-conversion
swift run rukey --help

FAQ

Частые вопросы

Rukey работает офлайн?

Да. Оба словаря встроены в приложение, и вся обработка идёт на вашем Mac. Интернет нужен только для проверки обновлений.

Что происходит с паролями и Secure Input?

В полях с защищённым вводом Rukey отступает автоматически: macOS сообщает о Secure Input, и приложение не вмешивается в набор.

Как отменить исправление?

Нажмите Option один раз — Rukey вернёт исходный текст. Если отменять одно и то же слово несколько раз, приложение запомнит его и перестанет исправлять.

Какие версии macOS поддерживаются?

macOS 13 (Ventura) и новее.

Есть ли телеметрия?

Нет. Rukey не собирает аналитику и не отправляет данные — сеть используется только для проверки и загрузки обновлений через Sparkle.

Как исключить приложение?

Добавьте его bundle ID в ~/.config/rukey/exclude.json — например, {"excludeBundleIDs": ["com.apple.Terminal"]}. Терминалы можно исключить разом флагом --exclude-terminals, отдельное приложение — флагом --exclude-bundle <id>. Подробнее — в README.

Это бесплатно?

Да. Rukey распространяется на условиях Apache-2.0, исходный код открыт на GitHub.
