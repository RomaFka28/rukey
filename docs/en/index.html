PROBLEM

The word is there, the letters are not

You type ghbdtn, and ghbdtn stays on the screen, though you meant «привет». Erase it, switch the layout, type it again — a small loss that repeats many times a day.

ghbdtn → привет
руддщ → hello

Rukey catches it the moment you type: the word is already written, the layout is already wrong — and it gives you back what you meant to say.

HOW IT WORKS

Two dictionaries and one check

Inside the app are two dictionaries: ≈46 000 English and ≈48 000 Russian words. Every word is checked against them and against the flipped layout. A correction fires only when the original spelling is absent from the dictionary and the flipped one is present. So «привет» stays «привет», and ghbdtn becomes «привет».

The dictionaries are bundled into the app: everything works offline, with no network calls.

The menu bar app and the rukey daemon share one engine from RukeyCore — they behave identically.

One Option tap to undo

If a correction was unwanted, press Option once: Rukey restores the original text. When the same word is undone several times, the app remembers it and stops touching it.

Secure Input

In fields with Secure Input — passwords, payment forms — Rukey steps aside automatically and changes nothing.

INSTALL

Three steps

  1. Download Rukey-*.dmg from the releases page and open the disk image.
  2. Drag Rukey.app to the Applications folder.
  3. Launch the app and grant access: System Settings → Privacy & Security → Accessibility.

Once running, Rukey lives in the menu bar — there is no Dock icon.

USAGE

Menu bar and CLI

Menu bar

In the menu bar Rukey shows its state and the current layout. The same menu opens Settings… and Log…, and Check for Updates… runs an update check through Sparkle.

Working · Paused: Secure Input · No Accessibility permission

CLI

The rukey daemon is the same engine without a UI.

rukey
rukey --check-permissions
rukey --exclude-terminals
rukey --exclude-bundle <id>
rukey --test-conversion
rukey --help

Configuration

  • ~/.config/rukey/exclude.json — exclusions and general settings
  • ~/.config/rukey/custom.json — user dictionary
  • ~/.config/rukey/learned.json — undo-learning data
FAQ

Common questions

Does Rukey work offline?

Yes. Both dictionaries are bundled into the app, and all processing happens on your Mac. The internet is needed only for update checks.

What happens with passwords and Secure Input?

In fields with secure input Rukey steps aside automatically: macOS signals Secure Input, and the app does not interfere with typing.

How do I undo a correction?

Press Option once — Rukey restores the original text. If you undo the same word several times, the app remembers it and stops correcting it.

Which macOS versions are supported?

macOS 13 (Ventura) and newer.

Is there telemetry?

No. Rukey collects no analytics and sends no data — the network is used only to check for and download updates via Sparkle.

How do I exclude an app?

Add its bundle ID to ~/.config/rukey/exclude.json — for example, {"excludeBundleIDs": ["com.apple.Terminal"]}. Terminals can be excluded in one go with --exclude-terminals, a single app with --exclude-bundle <id>. More in the README.

Is it free?

Yes. Rukey is distributed under Apache-2.0, with the source open on GitHub.
